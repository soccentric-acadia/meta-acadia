# meta-acadia

Yocto layer for **Acadia** (Raspberry Pi 5), part of the open-source Acadia platform from [SoCcentric](https://soccentric.com).

It is used by [Acadia-OS](https://github.com/soccentric-acadia/Acadia-OS), which holds the kas configuration that builds a full image.
